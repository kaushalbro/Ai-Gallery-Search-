# Changelog

All notable changes to **LensVault** are documented here.

## [1.0.0] - 2026-10-05

### Added
- Complete offline-first architecture with on-device PP-OCRv6 Tiny pipeline.
- Room Database with FTS full-text search index for sub-100ms queries across galleries.
- Interactive Bounding Box overlay viewer with single & multi-box tap selection and copy tools.
- Entity detection engine for URLs, Emails, Phone Numbers, IP Addresses, Wi-Fi credentials, and Invoices.
- Durable prioritized background indexing queue with adaptive concurrency (1–4 workers).
- Exact (xxHash3/SHA-256) and near-duplicate (64-bit DCT pHash) deduplication engine.
- On-device benchmark calibration suite comparing CPU, XNNPACK, and NNAPI execution providers.
- Seed dataset generator with 8+ high-fidelity offline sample cards (receipts, errors, Wi-Fi stickers, flight passes).
- Obsidian-Cyan Dark Material 3 theme with fluid edge-to-edge layout.
- Comprehensive technical documentation suite.
